# AI Sandbox для Android

Проект приложения для создания и запуска 2D/3D-игр с помощью пресетов, визуального конструктора и OpenAI.

[Подробное техническое задание](docs/TECHNICAL_SPECIFICATION_RU.md)

В ТЗ описаны полноценный 2D/3D-редактор, встроенный Godot, изолированная Python-логика, Go backend с dotenv/Goose/PostgreSQL и безопасная интеграция с production-каталогом ModelsFolder.

Реализация начата. Есть [Android-прототип](android/README.md), [доверенный Godot host](engine/godot-host/README.md), [контракты проекта](contracts/README.md) и [Go backend](backend/README.md).

Backend умеет: вход по email с кодом подтверждения, хранение проектов с ревизиями, и конвейер из шести AI-агентов (архитектор, гейм-дизайнер, разработчик, тестировщик, ревьюер, ревизор), который собирает из текстового запроса законченную игру — с камерой, физикой, противниками, HUD и условиями победы и поражения. Модели вызываются через kie.ai: основная — Claude, резервная — GPT. Между разработчиком и тестировщиком стоит детерминированный компилятор на Go: он превращает компактную спецификацию уровня в строгий документ GameProject и проверяет геометрию по реальной дальности прыжка, поэтому уровень, который нельзя пройти, до пользователя не доходит.

Ещё не готовы: исполнение игровых компонентов во встроенном Godot (host пока рисует только примитивы), загрузка моделей из каталога, выполнение Python и полноценный редактор на Android.
